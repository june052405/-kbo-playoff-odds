# KBO 가을야구 진출 확률 시뮬레이터

매일 아침 잔여 경기를 몬테카를로로 시뮬레이션해 응원팀의 포스트시즌 진출 확률을
계산하고, 결과를 메신저로 전송한다.

## 문제 정의

시즌 중 매 경기를 확인하기 어려운 상황에서, "지금 우리 팀은 가을야구에 갈 수 있는가"를
**하나의 숫자로 매일 자동 갱신**받는 것이 목표다. 대시보드가 아니라 푸시 알림 형태인
이유는, 접속해서 봐야 하는 도구는 애초의 문제(매일 확인하지 못함)를 해결하지 못하기 때문이다.

## 구조

```
data/standings.csv   현재 순위 (입력)
data/schedule.csv    잔여 경기 일정 (입력)
data/history.csv     일자별 확률 이력 (자동 누적)

kbo_sim.py           승률 모델 · 몬테카를로 · 검증 · 레버리지 분석
make_schedule.py     잔여 일정 생성기 (실제 KBO 일정 확보 전 임시)
notify.py            이력 기록 · 추이 그래프 · 브리핑 생성 · 알림 전송
run_daily.py         메인 실행
validation_demo.py   초기 구현의 결함 2건 재현
```

## 방법

**승률 모델 — log5 (Bradley-Terry)**
단순 시즌 승률이 아니라 두 팀의 상대 전력으로 경기별 승률을 계산한다.
홈 어드밴티지는 오즈비 1.15로, 무승부는 실측 발생률 2.2%로 반영한다.

**몬테카를로**
잔여 177경기를 20만 회 시뮬레이션해 최종 순위 분포를 얻고, 상위 5팀 진입 빈도를
확률로 환산한다.

**레버리지(민감도) 분석**
경기별로 `P(진출 | 승) − P(진출 | 패)`를 계산해 어떤 경기가 확률을 가장 크게
흔드는지 식별한다. 같은 시뮬레이션 집합을 경기 결과로 조건부 분할하므로 추가
연산이 들지 않는다.

## 검증

결과를 신뢰하기 전에 매 실행마다 아래를 확인한다.

| 검사 | 근거 |
|---|---|
| 전 구단 진출 확률의 합 = 5.000 | 매 시뮬레이션마다 정확히 5팀이 진출하므로 기댓값의 합은 반드시 5 |
| 팀별 잔여 경기 합 = 총 경기 × 2 | 일정 데이터 정합성 |
| 모든 확률이 [0, 1] | 기본 범위 검사 |
| 최저 확률의 상대표준오차 | 저확률 추정일수록 더 많은 시행이 필요 |

첫 번째 불변식은 **정답을 몰라도 계산할 수 있기 때문에** 자체 검증 기준이 된다.
초기 구현은 이 값이 5.10으로 나왔고, 추적 결과 순위 동률 처리 누락이 원인이었다.
`validation_demo.py`에서 재현할 수 있다.

## 실행

```bash
pip install numpy pandas matplotlib
python make_schedule.py     # 임시 일정 생성 (실제 일정으로 교체 권장)
python run_daily.py
```

환경변수 `DISCORD_WEBHOOK`, `ANTHROPIC_API_KEY`를 설정하면 알림과 브리핑이 동작한다.
미설정 시 콘솔 출력으로 대체되며 파이프라인은 그대로 완주한다.

자동 실행은 `.github/workflows/daily.yml` (매일 KST 07:00). 서버가 필요 없고,
실행 이력이 커밋 로그로 남는다.

## 한계

- `data/schedule.csv`는 팀별 잔여 경기 수만 맞춘 임시 대진이다. 확률의 절대값은
  실제 KBO 일정으로 교체한 뒤에야 의미를 갖는다.
- 팀 실력을 시즌 누적 승률로 고정했다. 최근 폼, 선발 로테이션, 부상은 반영하지 않는다.
- 승률 동률은 무작위로 가른다 (실제 KBO 규정은 상대전적 우선).
